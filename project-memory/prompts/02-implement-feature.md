# Prompt triển khai tính năng

```text
Đọc AGENTS.md và tài liệu ngữ cảnh trong project-memory/ trước khi làm.

Tính năng: [Tên tính năng]
Người sử dụng: [Bé / phụ huynh / quản trị viên]
Hành vi cần có: [Mô tả hoặc ví dụ cụ thể]
Phạm vi: [Frontend / backend / AI / tích hợp]
Tiêu chí hoàn thành: [Những điều cần hoạt động để coi là xong]
Ràng buộc bổ sung: [Nếu có]

Đối chiếu schema và code hiện tại trước khi chọn cách triển khai. Giữ các quy tắc NFC, phân tuyến ba model và giới hạn CAMERA không chấm hướng/thứ tự nét. Khi chưa có model thật, giữ kết quả chờ xử lý rõ ràng, không bịa điểm.

Thực hiện công việc trong phạm vi trên, chạy kiểm tra phù hợp. Khi xong, cập nhật project-memory/STATUS.md và quyết định mới trong PROJECT_CONTEXT.md nếu có. Báo ngắn gọn thay đổi, cách chạy/xem và phần chưa xác minh.
```
