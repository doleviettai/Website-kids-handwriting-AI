# Prompt dùng lại

Các file ở đây là mẫu văn bản để dán vào cuộc trò chuyện AI, không tự thực thi công việc.

| Prompt | Khi dùng |
| --- | --- |
| [01-resume-project.md](01-resume-project.md) | Mở phiên mới hoặc đổi AI/công cụ |
| [02-implement-feature.md](02-implement-feature.md) | Thực hiện một tính năng cụ thể |
| [03-update-handoff.md](03-update-handoff.md) | Cập nhật bộ nhớ trước khi dừng phiên |
| [04-full-project-spec.md](04-full-project-spec.md) | Đặc tả đầy đủ người dùng gửi; làm từng bước, nối model sau |

Thay phần `[ ... ]` bằng yêu cầu thật. Thêm prompt mới bằng tên mô tả dễ hiểu, ví dụ `05-auth-api.md`; ghi rõ đầu vào, phạm vi, tiêu chí hoàn thành và tình trạng mới là mẫu/đã sử dụng nếu cần lưu lịch sử. Không lưu thông tin đăng nhập hoặc dữ liệu thật của trẻ trong prompt.
